General Rules

These rules apply to all players on both the server and Discord.

Core Principle

The purpose of these rules is to ensure fair, enjoyable, and competitive gameplay.

The spirit of the rules always takes priority over literal interpretation.

A behavior may still be considered a rule violation even if it is not explicitly prohibited, if it provides an unfair advantage or attempts to bypass intended gameplay.

The Admin Team reserves the right to treat such behavior as a rule violation.

Cheating and Exploits

The following are strictly prohibited:

  • Using cheats.
  • Duplication / Duping.
  • Using exploits.
  • Abusing trader or animation glitches.

All such incidents must be reported to the Admin Team.

Prohibited Movement and Exploit Techniques

The following are prohibited:

  • Using NVIDIA Inspector.
  • Moonwalking.
  • Ice Sliding.
  • Animation Abuse.
  • Vortexing.
  • Using BBP exploits, such as placing C4 through walls.
  • Abusing collision bugs.
  • Using any hitbox or model exploit.

Associating with Cheaters

If you knowingly play with a proven cheater, you may receive the same punishment as the cheater.

If you become aware that a teammate is cheating, or if you strongly suspect suspicious behavior, you are required to report it to the Admin Team.

Choose carefully who you play with.

Steam Accounts

  • Using a private Steam profile is prohibited.
  • Using Steam accounts purchased from third-party websites is prohibited.
  • Only one Steam account may be used per person on the server.
  • Using alternate accounts for any purpose is prohibited.
  • If a banned player attempts to return using a new or alternate account, it will result in a permanent ban.

Cheating Accusations

Cheating accusations may only be submitted through a ticket.

The following are prohibited:

  • Making accusations in-game chat.
  • Making accusations on Discord.
  • Making accusations in global chat.

Violating this rule may result in a ban.

Metagaming

Using or sharing out-of-game information that provides an advantage is prohibited.

  • Revealing the location of another player's base.
  • Revealing where a raid is taking place.
  • Revealing another player's current location.
  • Using information obtained through streams, Discord, or any other external source.

Example: “Good fight in Zeleno, GG” is not considered metagaming.

Base and raid metagaming may result in a ban.

Logging Out Near Keycard Loot Rooms

Logging out within 50 meters of a keycard loot room is prohibited, including before server restarts.

Active Events

Logging out within 500 meters of an active event is prohibited:

  • KOTH.
  • Airdrop.
  • Other active events.

Building within active event zones is prohibited if it interferes with combat. Airdrops are exempt from this rule.

Impersonation

  • Intentionally using or imitating another player's name is prohibited.
  • Changing your character name to another player's name for deceptive purposes is prohibited.
  • Impersonating an Admin or Staff member is prohibited.

Roadblocks

Intentionally creating roadblocks anywhere on the map is prohibited.

This includes:

  • Parking vehicles on roads.
  • Using any object as a temporary roadblock.

This rule applies even if the road is not completely blocked.

Stream Sniping

Using a stream to gain an advantage or specifically hunt a streamer is prohibited.

Gameplay Recording

Recording your gameplay is strongly recommended so evidence is available in case of disputes.

Advertising Other Servers

The following are prohibited:

  • Advertising other DayZ servers.
  • Promoting other servers on Discord or side chat.
  • Publicly insulting or trash-talking the server.

Violating this rule may result in a ban.

Virtual Machines and Cloud Gaming

The following are prohibited:

  • Using virtual PCs.
  • Using Cloud Gaming services.

Exception: NVIDIA GeForce NOW is permitted.

Contacting Admins and Requesting Assistance

Players may contact Admins and Moderators through the following methods:

  • Opening a ticket.
  • Using the in-game-help channel on Discord.
  • Using the Support Voice Channel.

This system helps players because tickets are much more likely to be seen quickly than asking “Is an admin online?” in-game.

Guidelines

  • Not knowing the rules is not an excuse.
  • The rules may be updated at any time.
  • If you have a dispute, open a ticket instead of arguing in chat.
  • Admin decisions are final.

Punishments

Violating the rules may result in a warning, mute, kick, temporary ban, or permanent ban depending on the severity of the offense.
