General Rules

1. Cheating and Exploits

The following are strictly prohibited:

  • Using cheats
  • Hacking
  • Duplication (Duping)
  • Using exploits
  • Abusing trader or animation glitches

All such cases must be reported to the admins.

2. Prohibited Movement and Exploit Techniques

The following are prohibited:

  • NVIDIA Inspector
  • Moonwalking
  • Ice Sliding
  • Animation Abuse
  • Vortexing
  • BBP exploits (e.g. placing C4 from outside walls)

3. Cooperation with Cheaters

If you knowingly play with a proven cheater, you may receive the same BAN as if you were cheating yourself.

If you become aware that your teammate is cheating or you consider your teammates suspicious, you must report it to the Admins.

Choose carefully who you play with.

4. Steam Accounts

4.1. Using a private Steam account is prohibited.

4.2. Using a Steam account purchased from any external website is prohibited.

4.3. Only one Steam account may be used per person on the server.

Using alt accounts for any purpose is prohibited.

4.4. If a banned player attempts to return with a new or alternative account, it will result in a permanent ban.

5. Cheating Accusations

Cheating-related accusations may only be reported through a ticket.

It is prohibited to write such accusations in:

  • Ingame Chat
  • Discord

Violating this rule may result in a ban.

6. Metagaming (Base & Raid)

PROHIBITED

  • Publicly revealing the location of other players' bases
  • Revealing where a raid is taking place
  • Revealing other players' current positions

(e.g. Good fight in Zeleno, gg – this is not meta)

Base and Raid Metagaming is punishable by ban.

7. Logging Out Near Keycard Loot Rooms

Logging out within 50 meters of keycard loot crate rooms is prohibited, including before server restarts.

8. Active Events

Logging out within 500 meters of an active event is prohibited:

  • KOTH
  • Airdrop
  • Other active events

Building in active event areas (except Airdrop) is also prohibited if it interferes with combat (e.g. blocking stairs or corridors).

9. Impersonation

Intentionally using or imitating another player's name is prohibited.

Players may not change their character name to another player's name for deceptive purposes.

10. Roadblocks

Intentionally building roadblocks anywhere on the map is prohibited.

11. Stream Sniping

Using a stream to gain an advantage or specifically hunt a streamer is prohibited.

12. Gameplay Recording

Recording gameplay (video recording) is recommended so that evidence is available in disputed situations.

13. Admin Impersonation

Pretending to be an admin is prohibited:

  • In Global Chat
  • On Discord
  • In-game voice communication

14. Advertising Other Servers

Prohibited:

  • Advertising other DayZ servers
  • Promoting other servers on Discord or Side Chat
  • Publicly insulting the server (“trash talking”)

Violating this rule may result in a ban.

15. Virtual Machines and Cloud Gaming

Prohibited:

  • Using virtual PCs
  • Using Cloud Gaming services

Exception: NVIDIA GeForce NOW is allowed.

16. Contacting Admins and Requesting Help

Admins and moderators can be contacted in the following ways:

  • Creating a ticket
  • Using the in-game-help channel on Discord
  • Support VC room

This decision helps players, because tickets are more likely to be seen sooner than “Is there an admin online?” questions ingame.

Violating the rules may result in a warning, mute, kick, or permanent ban depending on the severity of the case.
